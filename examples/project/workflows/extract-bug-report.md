# Extract a bug report

Fields to extract for a request categorized as `bug_report`, in this order. Use these exact
keys. Leave a field out if the text does not state it, and list it in `missingInfo` if it is
marked required.

1. `issue_id`: The issue id for workplus issue
2. `machine_ip`: The ip of the machine QA provided for debug and reproduced
3. `machine_password`: The password used in ssh login

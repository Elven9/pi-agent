# pi-agent usage

Do not guess pi-agent's flags or behavior. Learn them from the installed version first:

1. Run `pi --help` and read the extension flags it lists (the ones pi-agent adds, such as
   `--scenario`, `--project`, `--tags` and `--pi-agent-docs`).
2. Run `pi --pi-agent-docs` for the overview and the list of topics.
3. Before using a flag, read its topic: `pi --pi-agent-docs <topic>` (for example `scenario`
   before `--scenario`, `project` before `--project`).

Then follow what the help and docs say. They describe this install, so they take priority over
anything you remember about pi-agent.
